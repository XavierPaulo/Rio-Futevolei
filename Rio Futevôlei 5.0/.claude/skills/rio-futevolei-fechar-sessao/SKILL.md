# Fechar a sessão

1. **Resumo das novidades** do dia, por item pedido, em português curto (o que mudou + onde editar).
2. **Perguntas em aberto**: listar as que o autor ainda não respondeu.
3. **Projeto Claude**: atualizar `Projeto Claude/2 - Resumo do jogo.md` (na pasta Cachorrinho Na Rede Produções) com o estado atual e as perguntas em aberto; avisar o autor para trocar o arquivo no projeto do claude.ai.
4. **PDF de novidades** (só se pedido): formato celular retrato, uma novidade por bloco, salvar como `Rio Futevôlei 5.0/Novidades AAAA-MM-DD.pdf`.
5. **Git** (repositório na pasta Cachorrinho Na Rede Produções, ramo `main`):
   - `git status` para revisar; não incluir vídeos (`videos/`, `*.mp4`) nem `.claude/settings.local.json`.
   - Commit com mensagem em português dizendo o que mudou.
   - `git push` para o GitHub **só com o ok do autor**.
