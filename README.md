# Rio Futevôlei — Cachorrinho Na Rede Produções

Jogo de futevôlei no navegador. Cada pasta é uma versão:

| Pasta | Porta | O que é |
|---|---|---|
| Rio Futevôlei | 8765 | 1.x, primeira versão |
| Rio Futevôlei 2.0 | 8766 | editor de golpes |
| Rio Futevôlei 3.0 | 8767 | balanceamento |
| Rio Futevôlei 4.0 | 8768 | Tilt + Modo História |
| **Rio Futevôlei 5.0** | 8769 | **versão atual** |

Para jogar: dentro da pasta, `powershell -ExecutionPolicy Bypass -File serve.ps1 -Port <porta>` e abra `http://localhost:<porta>/`.
Os vídeos do teaser não vão para o GitHub (são grandes); ficam em `Rio Futevôlei 5.0/videos/` no computador.
